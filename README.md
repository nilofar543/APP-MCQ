# MCQ Exam App
1. Install Node.js (v18+) and MongoDB (or use a free MongoDB Atlas URI).
2. `npm install`
3. Copy `.env.example` to `.env` and set ADMIN_PASSWORD (and MONGO_URI if needed).
4. `npm start`
5. Teacher: http://localhost:3000/admin.html — Student link format: http://localhost:3000/exam.html?id=<examId>
